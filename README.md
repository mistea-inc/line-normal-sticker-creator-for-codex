# LINE通常スタンプ制作 for Codex

参考画像を基に、Codexと自然言語で相談しながら通常の静止画LINEスタンプを作るプロジェクトです。企画、文字なし原画の生成、VectorCraftでの文字加工、確認、PNGと登録用ZIPの準備まで進められます。

## 完成するもの

| 完成物 | 内容 |
|---|---|
| 編集ファイル | 1スタンプずつ編集できる `.vectorcraft` ファイル |
| スタンプ画像 | 背景透過PNGと、確認用の明暗背景画像 |
| Main・Tab | それぞれの登録仕様に合わせたPNG |
| 登録用ZIP | スタンプ画像とMain・Tabを格納した `upload.zip` |
| タグ検索候補 | 画像番号と対応する `tags.txt` |
| 登録ガイド | 画面画像付きの登録手順と、制作から審査待ちまでの操作GIF |

## 利用に必要なもの

- 自分のPCのファイルとコマンドを扱え、画像生成ツールを利用できるCodex。
- Python 3.11以上。利用できるPythonはCodexが確認します。
- VectorCraftを表示できるデスクトップ環境。
- 初回の依存ファイル取得に使うネットワーク接続。
- 自分が使用できるキャラクターの参考画像。

Windows・macOS・Linuxを対象にしています。OS、CPU、表示環境、権限設定により追加の準備が必要になる場合があります。Windowsではネイティブ実行とWSL2を区別します。アニメーションスタンプなど、通常の静止画以外の制作は対象にしていません。

## ダウンロードして開く

1. [公開リポジトリ](https://github.com/mistea-inc/line-normal-sticker-creator-for-codex)を開きます。
2. 緑色の **Code → Download ZIP** を選びます。
3. ダウンロードしたZIPを展開します。ZIPの中のまま使わず、展開したフォルダを保存してください。
4. 自分のPCのCodexで、展開したプロジェクトのフォルダを開きます。
5. 下の依頼文をCodexへ送ります。

[リリースページ](https://github.com/mistea-inc/line-normal-sticker-creator-for-codex/releases)のソースZIPも利用できます。Gitで取得したい場合は、上記URLと保存先をCodexに伝えて取得を依頼できます。

## 最初にCodexへ伝える文章

> このプロジェクトをセットアップして、LINEの通常スタンプ制作を始めてください。最初に利用環境と画像生成ツールの利用可否を確認し、参考画像と用途を相談してから、サンプル1点を作るところまで進めてください。

通常のコマンド実行やセットアップはCodexが担当します。フォルダを開くことやGitHubへ接続することだけで制作が自動実行されるわけではなく、この依頼から作業を始めます。

## 参考画像の準備

`input/references/` に参考画像を置き、Codexへ「参考画像を置きました。このキャラクターで、日常で使える丁寧なスタンプを作りたいです」と伝えます。別の場所にある画像のパスを伝えて、取り込んでもらう方法も使えます。

変えてほしくない顔、配色、衣装、左右の特徴や、名前表記も伝えてください。参考画像は元を保持したまま作品フォルダへコピーして使います。

## 制作の流れ

**相談 → サンプル確認 → 各スタンプ制作 → デザイン確認 → 書き出し → LINEへの登録**

用途・枚数・セリフを相談し、まずサンプルを確認します。方向性が決まったら各スタンプを制作し、例えば4点ずつ別のタブで調整します。サンプルは絵柄や読みやすさの判断基準とし、全点を同じ配置に固定するテンプレートにはしません。フォント・配色・構図は各セリフに合わせて選べます。

- [GIF付き制作手順書をMarkdownで読む](docs/workflow.md)
- [制作手順書のブラウザ版](docs/workflow.html)

ブラウザ版は、ダウンロードして展開したフォルダ内の `docs/workflow.html` を開いて使います。画像を押すとその工程のGIFを再生でき、他のGIFを再生すると前のGIFは停止します。操作例はmacOSで収録しています。

## 保存先と続きからの再開

作品は自分のPCの `projects/<作品名>/` に保存されます。

| フォルダ | 保存するもの |
|---|---|
| `references/` | 元の参考画像を保持したコピー |
| `artwork/` | 文字なし原画 |
| `designs/` | 編集可能なデザイン |
| `review/` | 確認用の画像 |
| `output/` | 最終PNG、Main・Tab、ZIP、タグ検索候補 |
| `production/`・`logs/` | 制作の対応情報、検査結果、実行記録 |

企画や進行、確認状況も作品内に記録します。続けるときは同じフォルダをCodexで開き、「前回の作品の続きから進めてください。保存済みのファイルと進行記録を確認して再開してください」と伝えます。

参考画像、作品、実行環境、個人の設定は `.gitignore` で追跡対象から除外します。自分のコピーを編集することはできます。作品のバックアップ先は自分の環境で決めてください。

## 困った場合

| 状況 | Codexへ伝えること |
|---|---|
| 画像生成が使えない | 「現在の環境で画像生成ツールが使えるか確認してください」 |
| VectorCraftが表示されない | OSと、WSL2を使っている場合はそのことを伝え、「ウィンドウの表示と起動ログを確認してください」 |
| 日本語やフォントが崩れる | 対象の画像番号と表示内容を伝え、「欠落文字とフォントの代替を確認してください」 |
| 再開する場所が分からない | 作品名や保存先を伝え、「既存データを確認して、未完了の工程から再開してください」 |

画像生成ツールの利用可否はCodexの環境に依存します。このプロジェクトが画像生成機能を追加するものではありません。使えない場合に、無断で有料の外部APIへ切り替えることもありません。

## LINEへの登録

完成した `output/upload.zip`、`tags.txt`、確定したタイトル・説明文を用意し、[LINE Creators Market](https://creator.line.me/ja/)で登録します。

- [スクリーンショット付き登録ガイド](docs/registration.md)
- [登録ガイドのブラウザ版](docs/registration.html)
- [LINE公式の制作ガイドライン](https://creator.line.me/ja/guideline/sticker/)

PNGの仕様やZIPの内容、参照画像・レビュー・出力の対応を検査しますが、画像の目視確認やLINEの審査を代わりに行うものではありません。登録前に現行の公式仕様と実際の画面を確認してください。
